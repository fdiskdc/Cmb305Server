# BNU 305 实验室服务器使用说明

面向第一次使用 Linux 服务器的生物专业同学。以 **SSH 登录 PVE 宿主机后执行命令**为主，帮助你找到自己的容器、管理数据，并在获分配后创建、重建、迁移和退役容器。

**配置核验日期：2026-11-04。** 本手册依据两台服务器的只读检查和现有管理脚本源码编写。登录连通性、配置、挂载和命令参数已核实；为保护在用环境，未实际执行创建、重建、删除或迁移演练。高影响操作应由负责维护服务器的同学陪同，先核对对象和备份。

## 从哪里开始

1. [下载加密登录材料](access/login-materials.zip)。**解压密码写在服务器机架上。** 只有获授权的实验室成员应使用这些材料。
2. 阅读 [学生使用手册](docs/学生使用手册.md)：首次登录、识别容器、日常操作、数据与空间、创建、重建及删除。
3. 需要跨服务器搬迁时，阅读 [迁移与交接](docs/迁移与交接.md)。文件迁移和完整容器迁移是不同的操作。
4. 维护人员可阅读 [配置核验与维护说明](docs/配置核验与维护说明.md)，了解证据、限制及待处理事项。

## 首次 SSH 登录

先解压访问包，在自己电脑上打开包内文件所在文件夹的终端。macOS / Linux 执行：

```bash
chmod 600 ./bnu-305server-1
ssh -i ./bnu-305server-1 -p 8005 root@192.168.3.181
```

Windows PowerShell 执行：

```powershell
ssh -i .\bnu-305server-1 -p 8005 root@192.168.3.181
```

登录服务器 2 时，把 IP 改成 `192.168.3.191`。第一次连接需与管理员核对服务器主机密钥指纹。密钥文件不是命令，不能把它的正文粘贴到终端、聊天或公开仓库。

成功后先执行下面三条**查看命令**：

```bash
hostname
whoami
pct list
```

主机名应与上表一致，用户名应为 `root`。`pct list` 显示的是本台服务器所有容器；列表可见不等于你有权操作其他同学的容器。

## 开始前必须分清的三件事

- **宿主机与容器：**宿主机是整台物理服务器；容器是分给个人的 Linux 工作环境。日常计算在自己的容器里完成。
- **槽位与容器编号：**`pve-labctl` 使用槽位，`pct` 使用容器编号（CTID）。二者不是同一个数字。必须先查登记关系。
- **系统盘与数据目录：**重建系统盘、删除容器、清理个人数据是不同操作。`/home/账号`、`/work`、`/scratch` 来自宿主机上的独立 ZFS 数据集，普通容器备份不包含这些绑定目录的数据。

> 当前两台共登记了 100 个学生槽位，不能自行挑选一个看起来空闲的编号。先由管理员分配自己的服务器、槽位、容器编号、账号和端口。

## 登录材料与公开范围

加密包采用 AES-256 ZIP 格式，包含 SSH 私钥、密码文件、二次验证材料和内部登录说明。请使用支持该格式的解压软件；系统自带解压工具报错时，不要直接认定密码错误。

- [加密包](access/login-materials.zip)
- [加密包 SHA-256 校验值](access/SHA256SUMS)

密码、私钥正文、二次验证密钥及安全入口路径不写入公开正文。解压后材料留在自己受保护的电脑上，不上传到个人公开仓库，不放进学生容器或共享目录。

## 本手册不会自动执行命令

文中的命令需要读者逐项核对后手动执行。查看、备份、停机、重建和删除都有明确的执行位置与影响说明。尤其不要在宿主机上直接执行 `reboot`、`shutdown`、`poweroff`，它们影响的是整台服务器；重启自己的容器应使用手册中的 `pct reboot` 流程。
